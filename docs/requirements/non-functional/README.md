# Non-functional requirements

One file per ISO/IEC 25010:2023 characteristic.

| Characteristic | Code |
| --- | --- |
| [Flexibility](flexibility.md) | `FLEX` |
| [Reliability](reliability.md) | `REL` |
| [Performance efficiency](performance.md) | `PERF` |
